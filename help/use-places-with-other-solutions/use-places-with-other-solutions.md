# Uso del servicio Places con otras soluciones de Adobe {#use-places-other-solutions}

Por sí solo, el uso del servicio de Places para recopilar datos de ubicación no resulta útil en la aplicación. Empezará a obtener un valor real de los datos de ubicación cuando los proporcione al resto de las soluciones de Adobe. Este proceso le permite utilizar los datos de ubicación para ofrecer experiencias personalizadas y tomar decisiones informadas.

Esta sección proporciona información sobre cómo integrar el servicio Places con otras extensiones de Experience Platform SDK para que pueda poner en marcha los datos de ubicación.
